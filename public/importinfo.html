Import Your Creations Into Playsculpt

Playsculpt lets creators import supported project files so they can keep building inside a browser-based game platform.

You can bring in compatible maps, builds, mesh parts, models, and supported Roblox-style scripts that you created or have permission to use.

Open Importer Create on Playsculpt

What This Page Means

The importer is made to help creators move their own projects into Playsculpt. It is not meant for stealing games, copying other creators, or using assets you do not own.

Playsculpt is independent and is not affiliated with Roblox. Only import content you made or have clear permission to use.

What Can Be Imported?

RBXL and RBXLX Files Import supported project files and convert them into Playsculpt projects.
Maps and Builds Bring over block builds, structures, rooms, towns, and map layouts.
Mesh Parts Move compatible mesh parts and models into the Playsculpt editor.
Supported Scripts Import compatible Roblox-style code and continue editing it with Playsculpt tools.
Parts and Properties Keep basic object data like position, size, color, material, and names.
Creator Assets Use your own models, builds, and project files as a starting point.

How Importing Works

Step 1: Export or save your supported project file.
Step 2: Upload the file to the Playsculpt importer.
Step 3: Playsculpt reads the project data and converts supported parts.
Step 4: Review the imported map inside the Playsculpt editor.
Step 5: Fix, edit, publish, or keep building your game.

Script Compatibility

Some scripts may work after being converted, while others may need edits. Playsculpt can support Roblox-style coding, but not every feature from another engine will work exactly the same.

Good For Simple gameplay scripts, object behavior, doors, coins, buttons, checkpoints, and basic systems.
May Need Fixing Advanced services, custom APIs, marketplace features, plugins, and platform-specific systems.
Editor Tools Scripts can be opened, reviewed, and adjusted inside Playsculpt after import.

Creator Safety Rules

To keep Playsculpt fair, creators must only upload projects and assets they own or have permission to use.

Do not upload stolen maps, leaked games, copied marketplace assets, private files, or another creator's work without permission.
Imported content may be reviewed or removed if it breaks copyright rules, community rules, or platform safety rules.
